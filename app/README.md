This directory contains the main application root for Neural City.

For full architectural details, database schemas, API routes, and 1-click launcher instructions, please refer to the main [Root README.md](file:///Users/fox/Desktop/city-signal/city-signal/README.md).

## Quick Developer Commands

Inside this directory (`app/`):

```bash
# Install dependencies
npm install

# Push schema to SQLite database (dev.db)
npm run db:push

# Seed starter dataset
npm run db:seed

# Run local development server
npm run dev

# Run unit test suite
npm run test

# Open Prisma Studio GUI
npm run db:studio
```
